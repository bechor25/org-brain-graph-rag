# ADR-0002: סוכני Opus 5 הם ה-LLM של הפייפליין

**סטטוס:** מאושר (2026-09-03)

**החלטה:** כל שלב הדורש LLM (חילוץ ישויות, סיכומי קהילות, Text2Cypher, שיפוט בהערכה) רץ כ-batch לסוכן Claude Code (Opus 5): קלט JSON + סכמה + דוגמאות → פלט JSON → ולידציה pydantic → רק קוד דטרמיניסטי כותב ל-Neo4j.

**למה:** אפס עלות API; replay ו-diff על כל batch; מדידה נקייה. מחיר: איטי יותר, ולא ניתן להריץ מסגרות שדורשות endpoint (MS GraphRAG) — את הרעיונות שלהן מממשים ידנית (GDS Leiden + סיכומים).

**כלל ברזל:** סוכן לעולם לא כותב ל-DB ישירות.
